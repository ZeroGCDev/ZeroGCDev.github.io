The ZeroTUI Cookbook

A terminal window doesn't have to be a wall of text. Recipes for turning it into dashboards, panels, tables, and live market screens — one widget at a time.

Give a terminal panels, tables, gauges, and widgets that update live, and it stops looking like scrollback and starts feeling like a real application — a dashboard, a settings screen, a trading desk. This cookbook is exactly that: build a widget, style it, drop it in a panel, arrange the panels with a layout, and wire the result into a running app. Every recipe below is something you can copy, change, and build on.

go get github.com/ZeroGCDev/zerotui
Widget

What appears

The piece that draws on screen or reacts to input — a label, a button, a table.

Layout

Where it sits

Decides position, size, and what surrounds it — rows, columns, panels, splits.

App

What runs it

Wires the root layout to a theme and drives the render loop.

Controls

The pieces a user actually touches.

Label

Static or changing text — titles, prices, status lines.

label := widget.NewLabel("Hello ZeroTUI")
label.SetText("Price: $123.45")

Button

An action the user triggers with keyboard or mouse.

button := widget.NewButton("SAVE", func() {
    // do something
})
button.Danger = true // destructive style

Toggle

ON / OFF settings, like notifications.

var enabled uint32
toggle := widget.NewToggle("Notifications", &enabled)
toggle.OnFlag, toggle.OffFlag = "ON", "OFF"
// enabled: 0 = OFF, 1 = ON

Slider

Choosing a value inside a range.

var level uint32 = 50
slider := widget.NewSlider(
    "Alert", &level, 0, 100, 1,
    widget.FormatInt("%"),
)

Live market & data viz

Widgets designed to update dozens of times a second without allocating.

Gauge

Progress, CPU, memory, capacity, health.

gauge := widget.NewGauge("CPU")
gauge.Value = 0.42
gauge.WarnAt, gauge.DangerAt = .70, .90

Sparkline

A small live graph — price, CPU, latency, network.

spark := widget.NewSparkline(120) // capacity
spark.Push(price)

PriceTicker

A frequently changing market price.

var price uint64 = 12345 // 123.45, 2 decimals
ticker := widget.NewPriceTicker("BTC-PERP", &price, 2, 2)
// auto-detects up/down and styles itself

OrderBook

Bids and asks for a trading UI.

book := widget.NewOrderBook(2, 2, 2)
book.SetLevels(
    []widget.Level{{Price: 10000, Size: 500}},
    []widget.Level{{Price: 10002, Size: 400}},
)

Data at scale

The virtualized versions only ever ask for the rows currently on screen — even at a million rows.

Table

Normal-sized datasets.

table := widget.NewTable([]widget.Column{
    {Title: "SYMBOL", Width: 12},
    {Title: "PRICE", Width: 12, Align: widget.AlignRight},
})
table.Rows = [][]string{{"BTC-PERP", "78900.00"}}
table.Zebra = true

VirtualTable

Very large datasets — transaction history, order flow.

table := widget.NewVirtualTable(columns, 1_000_000,
    func(row, col int) string {
        return getCell(row, col)
    })

List

A normal-sized selectable list.

list := widget.NewList([]string{
    "Market", "Orders", "Positions", "Risk",
})

VirtualList

A very large selectable list.

list := widget.NewVirtualList(1_000_000,
    func(i int) string { return itemAt(i) })

Interface chrome

Everything else a real application needs around the edges.

Tabs

Switching between sections like Positions / Orders / Risk.

tabs := widget.NewTabs([]string{"POSITIONS", "ORDERS", "RISK"})
tabs.Active = 1
tabs.OnChange = func(i int) { /* swap content */ }

TextInput

Entering text — symbols, quantities, search.

input := widget.NewTextInput("Symbol")
input.Border = true
input.SetValue("BTC-PERP")
// input.Numeric = true for numbers only

Panel

One widget inside a titled surface.

panel := widget.NewPanel("Status", label)
// several widgets together? use layout.Bordered

FastLogView

High-volume logs with a bounded buffer.

log := widget.NewFastLogView(10_000)
log.FollowTail = true
log.Append("connected to exchange")

CommandPalette

A Ctrl+K-style command launcher.

palette := widget.NewCommandPalette([]widget.Command{
    {Name: "Open Orders", Key: "O", Execute: func() {}},
})
palette.SetQuery("ord") // fuzzy match

Badge

Small status labels — LIVE, ERROR, NEW.

badge := widget.NewBadge("LIVE")
badge.Positive = true // or .Negative / .Info

Divider

Separating sections.

widget.NewDivider(true)  // horizontal
widget.NewDivider(false) // vertical

Stat

Compact dashboard metrics and KPIs.

stat := widget.NewStat("Latency", "1.2ms")
stat.Delta, stat.Up = "+12%", true

Spinner

A small loading indicator.

spinner := widget.NewSpinner("Loading")
spinner.Tick()

GradientBar

Utilization, capacity, health, confidence.

bar := widget.NewGradientBar(
    color.NordCyan, color.NordBlue, color.NordDimGray,
)
bar.Value = 0.65
ScrollBar, ResizeHandle, and CloseButton are low-level widgets you rarely build by hand — VirtualList/VirtualTable already provide scrolling, NewSplit already creates its own resize handle, and ClosableRounded manages its own close button.

Layout system

Widgets are the furniture. Layouts decide where the furniture goes.

Wrap

Put a single widget into the layout tree.

layout.Wrap(label)

NewFlex

Arrange children in a row or column.

layout.NewFlex(layout.Vertical,
    layout.Wrap(title),
    layout.Wrap(button),
)

Fix

A fixed amount of space along the flex direction.

layout.Fix(layout.Wrap(header), 3)

Flex1 / FlexN

Give the remaining space to a child, optionally weighted.

layout.Flex1(content)     // takes what's left
layout.FlexN(sidebar, 2)  // weighted share

Padding

Space around content so it isn't touching the panel edge.

layout.Padding(content, 2, 1, 2, 1)
// left, top, right, bottom

FixedSize

Give an entire layout a fixed width and height.

layout.FixedSize(panel, 72, 17)

Bordered

A titled border around a layout with several widgets.

layout.Bordered("Controls", formLayout, func() bool {
    return input.IsFocused()
})

BorderedRounded

The same, with rounded corners.

layout.BorderedRounded("Controls", content, nil)

ClosableRounded

A rounded panel that can be closed and reopened.

panel := layout.ClosableRounded("Order Book",
    layout.Wrap(orderBook), nil, func() { /* closed */ })
panel.Close()
panel.Show()

NewSplit

Two resizable panes.

split := layout.NewSplit(layout.Vertical, top, bottom, 0.60)
split.MinFirst, split.MinSecond = 20, 30

NewStack

Layer widgets — the later child draws above the earlier one.

layout.NewStack(
    layout.Wrap(background),
    layout.Wrap(content),
)

NewOverlay

Conditionally show something above the normal UI.

layout.NewOverlay(
    func() bool { return modalVisible },
    layout.Wrap(modal),
)

NewModal

A convenient centered modal with a dimmed background.

layout.NewModal(
    func() bool { return modalVisible },
    layout.Wrap(dialog), 60, 15,
)

Center

Center content inside a requested area.

layout.Center(layout.Wrap(label), 40, 5)

Responsive

A different layout depending on terminal width.

layout.Responsive(100, compactLayout, expandedLayout)
// width < 100 → compact, else expanded

NewRetained

Cache a large, stable dashboard until it's invalidated.

retained := layout.NewRetained(root)
retained.Invalidate() // call when geometry changes

Putting it together

Six widgets, three nested BorderedRounded panels, a grid for the stat row, and a split down the middle — that's a full operations dashboard in around forty lines. Live CPU, revenue and order KPIs, a traffic sparkline, and a system-health list all sit inside one running app.

package main

import (
    "fmt"
    "time"

    "github.com/ZeroGCDev/zerotui/app"
    "github.com/ZeroGCDev/zerotui/color"
    "github.com/ZeroGCDev/zerotui/layout"
    "github.com/ZeroGCDev/zerotui/style"
    "github.com/ZeroGCDev/zerotui/widget"
)

func main() {
    theme := style.CatppuccinMochaTheme()

    revenue := widget.NewStat("REVENUE", "$128.4K")
    revenue.Delta, revenue.Up = "+14.8%", true
    orders := widget.NewStat("ORDERS", "2,481")
    orders.Delta, orders.Up = "+8.2%", true
    latency := widget.NewStat("LATENCY", "3.8 ms")
    latency.Delta, latency.Down = "-0.6 ms", true

    cpu := widget.NewGauge("CPU")
    cpu.ValueFn = func() float64 {
        return 0.42 + 0.08*float64(time.Now().Unix()%5)/4
    }
    cpu.WarnAt, cpu.DangerAt = .70, .90

    memory := widget.NewGradientBar(color.Cyan, color.Magenta, color.DimGray)
    memory.Value = .68

    traffic := widget.NewSparkline(40)
    for i := 0; i < 40; i++ {
        traffic.Push(40 + float64((i*i)%31))
    }

    health := widget.NewList([]string{
        "● API gateway       healthy",
        "● Database          healthy",
        "● Worker queue      healthy",
        "● Object storage    healthy",
        "● Search            healthy",
    })
    health.Background = &color.Panel

    badge := widget.NewBadge("LIVE")
    badge.Positive = true

    stats := layout.NewGrid(1, 3,
        layout.Wrap(revenue), layout.Wrap(orders), layout.Wrap(latency),
    )

    top := layout.BorderedRounded("KEY METRICS", stats, nil)
    chart := layout.BorderedRounded("TRAFFIC • LAST 40 SAMPLES", layout.NewFlex(
        layout.Vertical,
        layout.Fix(layout.Wrap(traffic), 4),
        layout.Fix(layout.Wrap(memory), 1),
    ), nil)

    right := layout.BorderedRounded("SYSTEM HEALTH", layout.NewFlex(
        layout.Vertical,
        layout.Fix(layout.Wrap(badge), 1),
        layout.Flex1(layout.Wrap(health)),
        layout.Fix(layout.Wrap(cpu), 1),
    ), nil)

    body := layout.NewSplit(layout.Horizontal, chart, right, .68)
    root := layout.NewFlex(layout.Vertical,
        layout.Fix(layout.Wrap(widget.NewLabel("  NOVA • OPERATIONS")), 1),
        layout.Fix(top, 4),
        layout.Flex1(body),
        layout.Fix(layout.Wrap(widget.NewLabel("  [q] quit")), 1),
    )

    if err := app.New(root, theme).Run(); err != nil {
        fmt.Println(err)
    }
}
