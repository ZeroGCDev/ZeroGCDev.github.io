ZeroTUI renders only what changed

Most Go terminal frameworks redraw the entire grid to update a single digit. ZeroTUI diffs the screen instead, so trading desks and telemetry dashboards can push a thousand updates a second without a garbage-collection stutter.

Repainting an entire terminal grid because one character changed is like reprinting a whole newspaper page to fix a typo in a single headline. That's what most Go TUI frameworks do on every tick, and the constant reallocation is what triggers garbage-collection pauses — exactly the kind of stutter you can't afford on a live order book or a logs dashboard.

ZeroTUI was built to remove that cost for high-frequency workloads: trading desks, telemetry monitors, and anything else that redraws dozens of times a second.

How it works

The mechanism is deliberately simple — three steps, run on every frame:

01

Remember the last frame

ZeroTUI keeps a copy of exactly what's currently on screen, cell by cell.

02

Diff against the new one

When fresh data arrives, it compares the new frame to the old one and finds only the cells that actually changed.

03

Write just those cells

Only the changed characters get sent to the terminal. Everything else is left alone — no reallocation, no garbage.

Because it isn't generating temporary memory on every draw, ZeroTUI can stream live charts, fast-moving logs, or dense dashboards at 60 FPS without lag or memory spikes.

Where to use it

Trading & market dashboards

Real-time crypto tickers, live order books, and stock monitors that can't afford a dropped frame.

System & telemetry viewers

Fast log viewers, server metrics, and CPU or memory monitors updating many times a second.

Ops & risk tools

Dense dashboards built on huge tables or virtualized data lists.

Getting started

Every ZeroTUI app is built from three things: a widget that draws something, a layout node that decides where it goes, and an app.App that runs the whole thing. Widget is what — layout is where.

Install

go get github.com/ZeroGCDev/zerotui

Hello, ZeroTUI

package main

import (
    "github.com/ZeroGCDev/zerotui/app"
    "github.com/ZeroGCDev/zerotui/layout"
    "github.com/ZeroGCDev/zerotui/style"
    "github.com/ZeroGCDev/zerotui/widget"
)

func main() {
    hello := widget.NewLabel("Hello, ZeroTUI!")
    root := layout.Wrap(hello)

    app.New(root, style.NordTheme()).Run()
}

Add a button, wire it to a label

The button's second argument is the function that runs when it's activated.

status := widget.NewLabel("Waiting...")
button := widget.NewButton("CLICK ME", func() {
    // runs when the button is activated
    status.SetText("Button was pressed!")
})

Arrange with Flex

layout.Vertical stacks components top to bottom; layout.Fix(..., 1) gives each one row.

content := layout.NewFlex(
    layout.Vertical,
    layout.Fix(layout.Wrap(status), 1),
    layout.Fix(layout.Wrap(button), 1),
)

You can also go horizontal — here the label takes a fixed width and the button fills the rest:

content := layout.NewFlex(
    layout.Horizontal,
    layout.Fix(layout.Wrap(status), 20),
    layout.Flex1(layout.Wrap(button)),
)

Add padding, then a panel

content := layout.Padding(layout.Wrap(button), 2, 1, 2, 1)
// left, top, right, bottom

Wrap it in a rounded, titled panel and it stops being loose text floating on the terminal:

panel := layout.BorderedRounded("Status", content, nil)

Theme it

Named colors, custom RGB, and full themes — Dracula, Catppuccin, Tokyo Night, Rosé Pine, and more — are all built in.

theme := style.NordTheme().Clone()
theme.Selected.Bg = color.RGB(70, 120, 190)
theme.Selected.Fg = color.White
theme.Panel.Bg = color.RGB(30, 34, 42)
app.New(root, theme).Run()

Put it together: a toggle that drives a label

package main

import (
    "fmt"

    "github.com/ZeroGCDev/zerotui/app"
    "github.com/ZeroGCDev/zerotui/layout"
    "github.com/ZeroGCDev/zerotui/style"
    "github.com/ZeroGCDev/zerotui/widget"
)

func main() {
    var enabled uint32

    status := widget.NewLabel("Notifications are OFF")
    toggle := widget.NewToggle("Notifications", &enabled)
    button := widget.NewButton("SHOW STATUS", func() {
        if enabled == 1 {
            status.SetText("Notifications are ON")
        } else {
            status.SetText("Notifications are OFF")
        }
    })

    content := layout.NewFlex(layout.Vertical,
        layout.Fix(layout.Wrap(widget.NewLabel("ZeroTUI")), 1),
        layout.Fix(layout.Wrap(toggle), 1),
        layout.Fix(layout.Wrap(button), 1),
        layout.Fix(layout.Wrap(status), 1),
    )

    padded := layout.Padding(content, 5, 2, 5, 2)

    card := layout.BorderedRounded(
        "Notifications",
        padded,
        func() bool { return true },
    )

    root := layout.FixedSize(card, 48, 13)

    if err := app.New(root, style.TokyoNightTheme()).Run(); err != nil {
        fmt.Println(err)
    }
}

That's the actual 48×13 fixed-size card it renders. Press the button below to see what SHOW STATUS does to the label:
